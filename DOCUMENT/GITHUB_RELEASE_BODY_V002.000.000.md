# パス金庫 V002.000.000

## ダウンロード

下の Assets から以下のファイルをダウンロードしてください。

```text
PassKinko_V002.000.000_Windows.zip
```

GitHubが自動表示する `Source code (zip)` / `Source code (tar.gz)` は開発者向けです。通常利用する場合は不要です。

## 使い方

1. `PassKinko_V002.000.000_Windows.zip` をダウンロードします
2. ZIPを展開します
3. 展開したフォルダ内の `パス金庫.exe` を起動します
4. 初回起動時にマスターパスワードを設定します

## 主な変更

* ウェブサイトを複数登録できるようにしました。
* 詳細画面の削除ボタンを右端に配置し、削除前に確認メッセージを表示します。
* ロック解除画面のボタン配置を調整し、狭い画面でもはみ出しにくくしました。
* 検索画面から設定画面へ進めるようにし、マスターパスワード更新、エクスポート、初期化、Windows Hello設定をまとめました。
* 初期化はマスターパスワード再入力を必須にし、既存データを退避してから初期状態に戻します。
* Windows Helloによるロック解除を追加しました。マスターパスワード解除は引き続き利用できます。
* 複数サイズ入りの高解像度アイコンへ更新しました。
* マスターパスワード由来の鍵導出に Argon2id を使用します。

## 注意事項

`パス金庫.exe` だけを取り出さず、展開後のフォルダ一式を同じ場所に置いたまま起動してください。

必要な主なファイル:

```text
パス金庫.exe
パス金庫.dll
パス金庫.deps.json
パス金庫.runtimeconfig.json
Assets\
```

## 保存先

登録データや設定ファイルは、利用者のPC内の以下に保存されます。

```text
%LOCALAPPDATA%\PassKinko\
```

登録したサービス名、ユーザー名、ID、パスワード、メモ等を、開発者のサーバーや外部サービスへ自動送信する機能はありません。

CSV出力、バックアップファイル、クリップボード、画面共有、クラウド保存等の管理は、ユーザー自身の責任で行ってください。

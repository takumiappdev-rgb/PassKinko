# パス金庫 V001.000.000 リリースノート

## 位置づけ

本版は、v10.2リリース候補をベースにした初回リリース番号版です。

## 主な変更

- プログラムバージョンを `V001.000.000` として定義。
- ロック解除画面の右下にバージョンを小さく表示。
- `build_release.bat` を制限付きNuGet環境でも通しやすいReleaseビルド方式へ変更。
- 単一EXE発行で発生していた `Microsoft.NET.ILLink.Tasks` 取得エラーを回避。

## リリースビルド

```bat
build_release.bat
```

出力先:

```text
RELEASE\PassKinko_V001.000.000\パス金庫.exe
```

対象PCには .NET 8 Desktop Runtime が必要です。

## 注意

本ZIPにはローカルデータ、テストデータ、旧バージョンの保存データ、ビルド成果物は含めません。

# パス金庫 V002.000.000 リリースノート

## リリース対象

GitHub Releases の Assets に添付するファイル:

```text
PassKinko_V002.000.000_Windows.zip
```

ZIP作成元:

```text
RELEASE\PassKinko_V002.000.000\
```

`Source code (zip)` と `Source code (tar.gz)` は開発者向けの自動生成ファイルです。一般ユーザー向けには案内しません。

## 主な変更

* ウェブサイトを複数登録できるようにしました。
* 詳細画面の削除ボタンを右端に配置し、削除前に確認メッセージを表示します。
* ロック解除画面のボタン配置を調整し、狭い画面でもはみ出しにくくしました。
* 検索画面から設定画面へ進めるようにし、マスターパスワード更新、エクスポート、初期化、Windows Hello設定をまとめました。
* 初期化はマスターパスワード再入力を必須にし、既存データを退避してから初期状態に戻します。
* Windows Helloによるロック解除を追加しました。マスターパスワード解除は引き続き利用できます。
* Windows Hello認証前にアプリを前面化し、認証画面が意図しない位置に出にくいよう調整しました。
* 複数サイズ入りの高解像度アイコンへ更新しました。
* Argon2idによる鍵導出に対応しました。

## 戻せるようにするための考慮

* 初期化時は既存の `settings.json` と `passkinko.db` を `quarantine_...` フォルダへ退避します。
* 複数ウェブサイト対応では旧単一URLフィールドも残し、旧DB署名も読み込み時に許容します。
* Windows Hello解除に失敗した場合でも、マスターパスワードで解除できます。

# パス金庫 V001.000.000 リリース用ソース


## バージョン

プログラムバージョン: `V001.000.000`

画面上では、ロック解除画面の右下に小さく表示します。

## リリースビルドについて

`build_release.bat` は、NuGet制限環境でも通しやすいように `PublishSingleFile` を使わないフレームワーク依存EXE方式にしています。

出力先:

```text
RELEASE\PassKinko_V001.000.000\パス金庫.exe
```

対象PCには `.NET 8 Desktop Runtime` が必要です。完全な単一EXE化は `Microsoft.NET.ILLink.Tasks` 等の取得が必要になる場合があるため、リリース初版では採用しません。

ローカルPC上で資格情報を管理する Windows / WPF アプリです。  
このZIPにはリリースビルド用のソース一式のみを含めています。ローカルデータ、テストデータ、旧バージョンの保存データは含めていません。

## 起動

```powershell
.\run_dev.bat
```

## 保存先

実行後のローカルデータは以下に作成されます。

```text
%LOCALAPPDATA%\PassKinko\
  settings.json
  passkinko.db
```

## 旧データが残っている場合

旧形式・破損・互換性なしのデータが残っていても、アプリは起動して「アクセス停止」または「ロック解除」画面を表示します。手動削除しなくても、画面上の以下で復旧方針を選べます。

- バックアップ復元
- 退避して新規開始

「退避して新規開始」は既存ファイルを削除せず、`quarantine_...` フォルダへコピー退避してから初期状態へ戻します。

## バックアップ

v10.2のバックアップは `settings.json` と暗号化済みDBをまとめた `.pkbk` 形式です。KDF saltを含むため、PC移行時にも正しいマスターパスワードがあれば復元できます。DPAPIに依存する運用状態は復元先PCで再構築します。

## マスターパスワードを忘れた場合

安全上、登録済みデータの復号はできません。  
ただし、ツール自体は「退避して新規開始」により再利用できます。退避データは削除されません。

## 注意

CSV出力は平文のユーザー名・パスワードを含みます。移行や確認が完了したら速やかに完全削除してください。


## リリース前スモークテスト

`build_release.bat` 実行後、以下を最低限確認してください。

- 初回設定
- 追加、検索、詳細表示
- 表示後30秒で伏字へ戻る
- コピー後30秒でクリップボード削除
- 編集、削除
- ロック、×、最小化、トレイ復帰
- CSV出力
- `.pkbk` バックアップ作成
- `.pkbk` 復元
- マスターパスワード更新
- DB破損時にアクセス停止へ進む

## 運用上の注意

マスターパスワード更新前には、念のためバックアップ作成を推奨します。

バックアップ復元後の5分待機中は、アプリを閉じると待機がやり直しになります。これはOS時刻変更による待機短縮を防ぐための仕様です。

# パス金庫 v10.2 セキュリティレビュー観点

## 確認対象

- マスターパスワード由来鍵によるAES-GCM暗号化
- AES-GCM Nonceの都度生成
- PBKDF2-HMAC-SHA256 600,000回
- vault HMAC署名
- DPAPIを運用状態保護に限定利用していること
- DPAPI復号失敗時に初期化しないこと
- バックアップにKDF saltとDBが含まれること
- 旧データが残っていてもアプリ起動自体は失敗しないこと
- ロック時にアクティブ鍵・詳細参照・一覧参照を破棄すること
- 通常保存と設定保存が一時ファイル経由であること

## ドキュメント方針

監査に必要な設計情報は記載するが、攻撃手順や悪用コードは記載しない。
